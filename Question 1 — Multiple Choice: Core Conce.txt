Question 5 — Operating Systems, Terminals, and Shells



a) What is a kernel, in plain language?

Answer:

The kernel is the core part of an operating system that acts as a bridge between software and hardware. It manages things like memory, CPU time, storage, and devices so that programs can run without needing to interact directly with the hardware.

(b) A classmate says: "I installed WSL, so now I have two completely separate operating systems, Windows and Linux, running side by side, each totally independent."

Answer:

Not exactly. WSL lets you run a Linux environment inside Windows, but it is still integrated with Windows and shares access to resources such as files, networking, and hardware. While it feels like a Linux system, it is not completely independent in the same way as having two separate computers.



(c) Explain the difference between a terminal (emulator) and a shell, and give one example of each.

Answer:

A terminal is the application window you use to interact with the command line, while a shell is the program inside the terminal that reads and executes your commands. For example, Windows Terminal is a terminal emulator, and bash is a shell.
