## Data and interpretation

The full course file contains 1,048,585 rows. The project analysis retained 1,044,597 postings after removing 3,988 empty records. The app loads the full course file when it is present; otherwise it loads fictional demo data. Confirm the active source before presenting findings.

Category totals can overlap because an advert may be listed in more than one category. Trends are interpreted from May 2023 onward because collection methods changed. The cause of the later drop in posting counts is unconfirmed. Advertised salaries and application counts describe records in adverts; they do not establish hiring outcomes or unique applicant counts.
